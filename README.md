# PDF Editor

Десктопный редактор текста в PDF в духе LibreOffice Draw: правит существующий
текст, сохраняя шрифт, размер, цвет и положение строк.

## Запуск

```bash
python3.12 -m venv venv
./venv/bin/pip install -r requirements.txt
./run.sh samples/sample.pdf
```

## Сборка приложения для macOS

```bash
brew install uv
./build_mac.sh arm64     # Apple Silicon → dist/PDF-Editor-<версия>-AppleSilicon.dmg
./build_mac.sh x86_64    # Intel (на M-маке собирается через Rosetta) → …-Intel.dmg
./build_mac.sh arm64 11  # то же для macOS 11 Big Sur → …-AppleSilicon-macOS11.dmg
./build_mac.sh x86_64 11 # → …-Intel-macOS11.dmg
```

Сборки для macOS 11 используют PySide6 6.7 (`requirements-build-macos11.txt`) —
последнюю версию Qt, собранную под Big Sur. Скрипт сам проверяет, что ни одна
библиотека внутри приложения не требует macOS новее заявленной.

Работает на macOS 12 Monterey и новее. Python для сборки берётся портативный
(python-build-standalone), Qt — PySide6 6.8 LTS: Python из Homebrew и Qt 6.12
требуют свежую macOS и на старых системах не запустятся.

Приложение подписано ad-hoc, без Apple Developer ID, поэтому на чужом Mac при
первом запуске Gatekeeper его заблокирует. Открыть: правый клик по
приложению → «Открыть» → «Открыть», либо «Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть». Без этого шага нужна подпись Developer ID и
нотаризация (платный аккаунт Apple Developer, $99/год).

После установки PDF можно открывать через Finder: «Открыть с помощью → PDF Editor»
или перетаскиванием на иконку в Dock.

## Управление

| Действие | Как |
|---|---|
| Править строку | двойной клик, `Enter` или `F2` → `Enter` сохранить, `Esc` отменить |
| Переместить | перетащить мышью; стрелки — на 1 pt, `Shift`+стрелки — на 10 pt |
| Удалить строку | `Delete` |
| Вернуть строку как было | `Cmd+Shift+R` |
| Отмена / повтор | `Cmd+Z` / `Cmd+Shift+Z` |
| Масштаб | `Cmd`+колесо, `Cmd +/-`, `Cmd+0` — 100 %, `Cmd+9` — по ширине |
| Страницы | миниатюры слева, `PgUp` / `PgDown` |

В статус-баре видно шрифт выделенной строки и каким шрифтом она будет записана.

## Как это работает

* `pdfeditor/document.py` — извлекает строки посимвольно (`rawdict`: позиция,
  шрифт, размер, цвет каждого символа). При правке старый и новый текст
  сравниваются по словам: неизменённые слова остаются на исходных
  координатах (с кернингом оригинала), новые набираются стилем заменённого
  слова, хвост строки сдвигается на разницу ширины. Старый текст стирается
  redaction-ом **только текста** — фон, линии и картинки остаются.
* `pdfeditor/fonts.py` — подбор шрифта: сначала встроенный в PDF (для
  подмножеств без `cmap` она восстанавливается из `ToUnicode`, а глифы без
  контуров отбрасываются), затем системный с тем же именем, затем то же
  семейство, затем замена по классу serif/sans/mono.
* `pdfeditor/canvas.py` — холст: страница рендерится растром под текущий
  масштаб, поверх — интерактивные рамки строк.
* `pdfeditor/mainwindow.py` — окно, undo/redo (`QUndoStack`), миниатюры, файлы.

## Ограничения

* Единица правки — строка; перенос текста в абзаце не делается.
* Повёрнутые страницы и вертикальный текст пока не редактируются.
* Если в PDF встроено подмножество шрифта, а введённой буквы в нём нет и
  такого шрифта нет в системе — используется похожий шрифт (видно в статус-баре).
* Встроенные CID-шрифты в формате CFF (часть PDF из InDesign/LaTeX) пока
  не переиспользуются — для них берётся системная копия шрифта или замена.
* Сканы (текст картинкой) не редактируются — нужен OCR.
